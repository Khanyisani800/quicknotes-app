# QuickNotes

QuickNotes is a lightweight, responsive note-taking web application built with vanilla HTML, CSS, and JavaScript. It allows users to quickly jot down, categorize, search, and manage their daily notes with data persistence through browser local storage.

## Features
- **Add Notes**: Create notes categorized under Personal, Work, or Study.
- **Input Validation**: Ensures notes are not empty and stay within the 200-character limit.
- **Dynamic Counter**: Automatically tracks and updates the total number of notes saved.
- **Real-Time Search**: Filter through your saved notes instantly.
- **Data Persistence**: Notes are saved using `localStorage` so they survive page refreshes.
- **Responsive Design**: Clean layout that adapts smoothly across desktop and mobile screens.
